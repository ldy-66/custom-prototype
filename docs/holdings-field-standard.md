# 持仓信息字段标准

本文件规范原型【数据-持仓信息】页面的展示字段。依据 2026-10-22 提供的三份客户持仓 Excel 的表头；仅使用表头和结构，不保存或复用其中的持仓记录。

## 页面视图与字段

### 对客

对应表头样例包含客户及资金账户字段，页面按以下标准顺序展示：

`客户名称`、`客户名`、`交易账户`、`交易对手号`、`交易对手名称`、`交易对手简称`、`资金账户号`、`资金账号`、`资金账号名称`、`框架名称`、`证券代码`、`证券名称`、`合约代码`、`合约名称`、`上市状态`、`可用数量`、`持仓数量`、`成本价`、`持仓均价`、`最新价`、`持仓盈亏`、`持仓盈亏率`、`持仓市值`、`期初数量`、`交易冻结数量`、`日内开仓成交数量`、`日内平仓成交数量`、`持仓类型`、`业务类型`。

### 对冲

### 明细

包含开仓、保证金、汇率和费用字段的表头样例，页面按以下标准顺序展示：

## 统一规则

- `证券代码/证券名称` 与 `合约代码/合约名称` 分开保留；证券行或合约行不适用的字段显示为空值占位，不互相改名。
- `市值` 在一份表中出现，另外一份表使用 `持仓市值`。原型统一列名为 `持仓市值`，并在字段映射中保留来源名 `市值`。这只是展示名统一，未据此确认两者的计算公式或数值定义完全一致。
- `客户名称` 与 `客户名`、`资金账户号` 与 `资金账号`、`持仓盈亏` 与 `平仓盈亏` 均保持为独立字段。
- `日内开仓成交数量/日内平仓成交数量` 与 `日间开仓数量/日间平仓数量` 保持各自原名，不在原型中合并。
- 查询页面保留证券、期货、债券分类切换；分类不是 Excel 中的 `交易市场`字段。表格不虚构 `交易市场` 列，展示 Excel 中实际出现的 `上市状态`。
- 不增加 Excel 未提供的 `T+0`、`T+1` 可用数量字段。

## 展示类型建议

Excel 样例数据单元格以文本保存，无法据此确认后端字段类型。原型展示建议：账号及代码按文本处理以保留前导零；数量、价格、金额、比率按数值展示；`开仓日期`按日期展示。小数位、单位、舍入、枚举值、字段公式及过滤条件仍以正式接口或业务定义为准。

演示页面仅使用合成数据，不使用 Excel 中的客户、账号和持仓明细。
