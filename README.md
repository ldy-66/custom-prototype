# Custom端原型

根据Custom端下单面板截图复刻的浅色桌面交易原型，作为后续需求改造的稳定基础版本。

## 分支约定

- `main`：Custom端基础复刻，只维护已确认的现有页面能力。
- `codex/消息通知改造`：在基础复刻上增加右上角消息铃铛和消息中心。
- 后续需求：每个需求从`main`新建独立的`codex/<需求名称>`分支，不直接污染基础版本。

## 本地运行

```powershell
python -m http.server 4174
```

访问 `http://127.0.0.1:4174`。

页面数据均为演示数据，不连接真实交易系统，也不会实际报单。

当前分支支持消息未读数量、订单/市场/风控/系统一级分类，以及母单、子单、全部拒单和沪深、港股、美股二级筛选。拒单详情区分订单层级、拒单环节和拒单原因；市场提醒展示休市时间、恢复时间和时区。休市日期为原型演示信息，生产实现应接入经确认的市场日历来源。
